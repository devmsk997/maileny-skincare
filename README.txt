MAILENY SKINCARE — LANDING PAGE
================================

Archivos:
- index.html
- css/style.css
- js/main.js

TECNOLOGÍAS
HTML5, CSS3, Bootstrap 5.3, JavaScript y Bootstrap Icons.

ANTES DE PUBLICAR
1. Abre js/main.js.
2. Cambia la constante WHATSAPP_NUMBER por el número real de WhatsApp en formato internacional, solo dígitos.
   Ejemplo de formato: 18095551234 (sin +, espacios ni guiones).
3. Reemplaza las fotografías de muestra de Unsplash por fotografías reales autorizadas de Maileny Skincare.
4. Actualiza los servicios para que coincidan con los tratamientos que realmente ofrece el negocio.
5. Añade testimonios auténticos con autorización de las clientas.
6. Verifica la dirección exacta en Google Maps. El mapa actual muestra la zona general de Bonao.
7. Prueba todos los enlaces y el sitio en un celular antes de publicarlo.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea o inicia sesión en GitHub.
2. Crea un repositorio nuevo, por ejemplo: maileny-skincare.
3. Sube index.html, la carpeta css y la carpeta js manteniendo esa estructura.
4. En el repositorio, entra en Settings > Pages.
5. En Build and deployment, selecciona Deploy from a branch, elige main y / (root), y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que indique.
   También puedes publicarlo en Netlify arrastrando la carpeta del proyecto en su panel de despliegue manual.

NOTAS
- El proyecto es una landing page estática; no tiene tienda, pagos ni reservas complejas.
- Los botones de reserva usan WhatsApp. No funcionarán hasta reemplazar el número de ejemplo.
- Las imágenes de Unsplash son imágenes temporales de demostración, no fotografías propias del negocio.
- La ubicación actual de Google Maps es aproximada (Bonao), no la dirección exacta del establecimiento.
- La publicación requiere una cuenta/plataforma de hosting y debe hacerse con las credenciales del propietario.

LOGO ACTUALIZADO
- El logotipo proporcionado por el cliente está en images/maileny-logo.png y se muestra en el encabezado y el pie de página.
